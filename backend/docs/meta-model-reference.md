Hosted Model API: Muse Wonder, Muse Spark, Muse Image, Muse Voice Transcribe, SAM 3.1. Open weights: Muse Glimmer and Muse Spark Open, deployed separately. Muse Code is a developer tool. SAM segmentation is not freshness assessment; Muse Voice Transcribe is speech-to-text, not speech synthesis. Contributor mode has distinct data-use terms from Standard mode. Always re-check official documentation before coding.
